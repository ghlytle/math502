We've seen in our study of vector spaces that there are more vector spaces beyond the standard Euclidean space. We can denote the vector space of polynomials as follows $$\mathbb{P}_n = \{a_0 + a_1x + a_2x^2 + \ldots + a_n x^n : a_i \in \mathbb{R}\}$$ Because this is a vector space of functions, we define operations within the space based on how they affect the input variable(s) to the functions. Here, vector addition and scalar multiplication produce two functions $(f+g)$ and $(\alpha f)$ that are defined by $$(f+g)(x) = f(x) + g(x)$$ $$(\alpha f)(x) = \alpha f(x)$$ Because we have constant terms in the polynomials, we know that $\dim(\mathbb{P}_n) = n+1$. Like other vector spaces, we can often describe $\mathbb{P}_n$ by a basis, a linearly independent set of vectors that spans the space. Suppose $\mathcal{B} = \{v_0(t), v_1(t), \ldots, v_n(t)\}$ is a set of basis vectors for $\mathbb{P}_n$. Then any polynomial $f(t) \in \mathbb{P}_n$ can be uniquely written as $$f(t) = \alpha_0 v_0(t) + \alpha_1 v_1(t) + \ldots + \alpha_n v_n(t)$$

Because this space is finite-dimensional, it's isomorphic to a Euclidean space — in this case $\mathbb{R}^{n+1}$. This allows us to introduce coordinate vectors to represent the elements of the vector space relative to a specified basis. In the example above, the polynomial $f(t)$ can be represented by $$[f(t)]_{\mathcal{B}} = \begin{bmatrix} \alpha_0 \\ \alpha_1 \\ \vdots \\ \alpha_n \end{bmatrix}$$ This relationship allows us to transform certain questions about these more abstract vector spaces into questions about linear systems in Euclidean space.

Interpolation

In many applications we collect data that we assume comes from some underlying function, whether it be position, or velocity, or revenue. If we want to know information from the function outside of our collected data, we often don't have access to the exact answer; we need an approximation. There are two standard approaches to this process — an approximation or an interpolation. The process of approximation is based on minimizing some error in the data (kind of like the line of best fit or the least squares problem in linear algebra). But we're going to focus on the latter option. The goal of interpolation is that, given data points $(x_i, y_i)$ for $i = 0\ldots n$, we find a polynomial of degree $n$, say $p(x)$, such that $$p(x_i) = y_i \qquad i = 0, 1, \ldots, n$$ One assumption here is that none of the $x_i$'s repeat in value; they are all distinct.

Because $p(x) = a_0 + a_1x + \ldots + a_n x^n$, each condition $p(x_i) = y_i$ is a linear equation for the unknown coefficients, which means we can turn this polynomial problem into a linear algebra problem!

Change of Basis

Instead of using the basis $\mathcal{B}$, we can introduce a new basis to reframe the interpolation problem. For convenience, let's consider the space $\mathbb{P}_2$, and the standard basis $\mathcal{B} = \{1, x, x^2\}$. We can find another basis as: $$\mathcal{L} = \left\lbrace \dfrac{1}{3}(x^2 - 4x + 3),\ -\dfrac{1}{2}(x^2 - 3x),\ \dfrac{1}{6}(x^2 - x) \right\rbrace$$

How do we know if this is actually a basis? You take the representation of each of the vectors in $\mathcal{L}$ in terms of the coordinate vectors of $\mathcal{B}$ and make a matrix out of it. That gives us: $$L = \begin{bmatrix} 1 & 0 & 0 \\ -\dfrac{4}{3} & \dfrac{3}{2} & -\dfrac{1}{6} \\ \dfrac{1}{3} & -\dfrac{1}{2} & \dfrac{1}{6} \end{bmatrix}$$ If the matrix $L$ is invertible, then the elements of $\mathcal{L}$ form a basis.

Cardinal Polynomials

Given a data set $\{(x_0, y_0), (x_1, y_1), \ldots, (x_n, y_n)\}$, we can define the $j$th cardinal polynomial as: $$\ell_j(x) = \prod_{\substack{i=0 \\ i \neq j}}^{n} \left(\dfrac{x - x_i}{x_j - x_i}\right)$$ This formula looks a little confusing, but let's look at an example of it for $n = 2$. $$\ell_0(x) = \dfrac{(x-x_1)(x-x_2)}{(x_0-x_1)(x_0-x_2)}$$ $$\ell_1(x) = \dfrac{(x-x_0)(x-x_2)}{(x_1-x_0)(x_1-x_2)}$$ $$\ell_2(x) = \dfrac{(x-x_0)(x-x_1)}{(x_2-x_0)(x_2-x_1)}$$

It turns out that these cardinal polynomials form a new basis $\mathcal{L}$, sometimes called the Lagrange Basis.

The ideas of interpolating polynomials are used to develop numerical integration rules, which can then be adapted for many tasks ranging from approximating area to solving differential equations! And behind all of it is the structure of vector spaces!
