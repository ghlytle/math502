The process of using computers to solve mathematical problems lies in the subject of Numerical Analysis. There is a lot of overlap and interdisciplinary work between numerical analysis and computer science. But there are some key differences. Computer science, for example, is concerned with the development of algorithms to optimize the performance and memory usage of a computer. While these are important considerations, numerical analysis is also concerned with creating algorithms that maintain accuracy and are numerically stable.

Absolute Error and Relative Error

When we examine errors in any sort of approximation, there are two general frameworks for the error. Let's suppose we are approximating the true value $y$ with the approximation $\hat{y}$.

  • The absolute error is the absolute value of the difference: $|y - \hat{y}|$.
  • The relative error measures the error compared to the true value (also known as percent-error): $\dfrac{|y-\hat{y}|}{|y|}$

How Big is a Vector?

When we consider the matrix equation $Ax = b$, we can implement our elimination strategies in a systematic fashion. The algorithm allows us to generate an approximate solution to the problem, which we can call $\hat{x}$.

A natural question to ask is: "How can I talk about absolute and relative error when there are vectors instead of numbers?" The solution to this quandary is a norm.

  • A norm is a function that takes in a vector and assigns to it a nonnegative number that gives an indication of its size.

There are lots of different norms, but there are three common ones. Let $\vec{x} = \begin{bmatrix} x_1 \\ x_2 \\ \vdots \\ x_n \end{bmatrix}$.

The Euclidean Norm or 2-norm corresponds to the length of the vector as measured by a ruler. $$\|\vec{x}\|_2 = \left(x_1^2 + x_2^2 + \dots + x_n^2\right)^{1/2}$$

The 1-Norm is based on the sum of the absolute values of the entries. $$\|\vec{x}\|_1 = |x_1| + |x_2| + \dots + |x_n|$$

The Infinity Norm returns the largest entry of the vector (based on absolute value). $$\|\vec{x}\|_\infty = \max_{1 \leq i \leq n} |x_i|$$

Errors in Gaussian Elimination

In the context of solving the matrix equation $A\vec{x} = \vec{b}$, we can compute an approximate solution. Let's call it $\hat{x}$ in what follows.

Given an approximate solution, we can calculate the relative error in a couple of different ways. We'll be using the $\infty$ norm of the associated matrices.

  • Compute the Relative Error directly $$\text{Error} = \dfrac{\|x-\hat{x}\|_\infty}{\|x\|_\infty}$$

  • Compute the relative residual. The residual vector is defined as $r = b - A\hat{x}$. The relative error can then be estimated by $\dfrac{\|r\|_\infty}{\|A\|_\infty \|\hat{x}\|_\infty}$.

Associated with every matrix $A$ is a number called the condition number, often denoted as $\kappa(A)$ (that's the Greek letter kappa if you need to know). We're going to investigate how this number relates to the process of solving a matrix equation numerically.

There's More to the Story

We've taken a look at how the size of the condition number $\kappa(A)$ affects the solution of linear systems. Conceptually we can think of the condition number as a measure of how easy a matrix is to invert. Matrices that are singular have a condition number of $\infty$. As we have seen, invertible matrices have finite condition numbers, but that number can be huge!

If we think of the set of all matrices and call the set of singular matrices $S$, then the condition number of a matrix is the inverse of the distance from the matrix $A$ to that set. $$\text{(Distance from } A \text{ to Singular Matrices)} = \dfrac{1}{\kappa(A)}$$ That means matrices with high condition numbers are "almost singular."

So what's going on? Whenever we implement a mathematical problem in a computer, there are tiny approximation errors that occur. In matrices with high condition number, those small errors are amplified so much that we can lose significance in the results. Mathematicians have developed other techniques to work with ill-conditioned matrices to help mitigate this amplification.
